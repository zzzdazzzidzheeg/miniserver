Перед выполнением задачи изучи контекст проекта.

1. Прочитай README.md, чтобы понять назначение проекта, его архитектуру на высоком уровне и инструкции по запуску.
2. Изучи подходящие конфигурационные файлы, чтобы определить используемые технологии, зависимости, правила форматирования и команды тестирования.
3. Изучи структуру проекта и найди файлы, относящиеся к задаче.
4. Если README противоречит исходному коду, ориентируйся на актуальный код и конфигурацию.
5. Не читай без необходимости все файлы репозитория. Расширяй контекст по мере необходимости.
6. Если важной информации не хватает, задай уточняющий вопрос, а не выдумывай детали.

После изучения контекста кратко перечисли найденные соглашения и предложи план реализации. Затем приступай к задаче, соблюдая существующий стиль проекта и не изменяя несвязанные части кода.
