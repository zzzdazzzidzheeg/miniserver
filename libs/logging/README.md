# Logger

Простой логгер для серверного приложения. Он пишет сообщения в консоль и, при необходимости, дополнительно сохраняет их в файл.

## Назначение

Логгер используется для:

- отслеживания состояния сервера;
- вывода диагностической информации во время разработки;
- записи предупреждений и ошибок в файл;
- фильтрации сообщений по уровню важности.

## Уровни логирования

Логгер поддерживает четыре уровня:

- `Debug` — подробная отладочная информация;
- `Info` — обычные информационные сообщения;
- `Warning` — предупреждения, которые не останавливают работу;
- `Error` — критические ошибки.

Порядок важности следующий:

`Debug < Info < Warning < Error`

## Основной API

### Класс `Logger`

```cpp
#include "logger.h"

Logger::configure(LogLevel::Info, "logs/server.log");
Logger::debug("Server", "Подробная диагностика");
Logger::info("Server", "Сервер запущен");
Logger::warning("Network", "Подключение к внешнему сервису медленное");
Logger::error("Storage", "Не удалось открыть соединение");
```

Уровень и путь к файлу задаются при запуске через раздел `logging` в `config/server.json`. В коде настройки применяются один раз через `Logger::configure(...)`. Методы класса для записи:

- `debug(...)`, `info(...)`, `warning(...)`, `error(...)` — логирование сообщений;
- `clear()` — очищает текущий лог-файл и записывает сообщение о сбросе.

### Функции-обёртки

Также доступны функции в стиле C:

```cpp
log_info("Application", "Запуск приложения");
log_warning("Router", "Некорректный запрос");
log_error("Server", "Ошибка обработки");
```

Доступны следующие функции:

- `log_clear()`
- `log_debug(...)`
- `log_info(...)`
- `log_warning(...)`
- `log_error(...)`

## Поведение логгера

### Вывод в консоль

Каждое сообщение всегда выводится в стандартный вывод (`std::cout`) в формате:

```text
[YYYY-MM-DD HH:MM:SS] [LEVEL] Component: message
```

Пример:

```text
[2026-10-03 12:30:45] [INFO] Server: Сервер запущен
```

### Вывод в файл

Если в конфигурации задан `logging.file`, логгер открывает файл в режиме добавления (`std::ios::app`). Пустое значение оставляет вывод только в консоль.

Это означает, что новые записи дописываются в конец файла, а не перезаписывают его.

### Фильтрация

Если установлен уровень, например `Info`, то сообщения уровня `Debug` не будут записываться.

Пример:

```json
{
  "logging": {
    "level": "warning",
    "file": "logs/server.log"
  }
}
```

## Очистка файла

Метод `clear()` очищает текущий файл логов и затем записывает сообщение:

```text
[YYYY-MM-DD HH:MM:SS] [INFO] Logger: Log file cleared
```

## Ограничения и замечания

- По умолчанию минимальный уровень — `Info`.
- Если файл не задан, логирование идёт только в консоль.
- Логгер потокобезопасен: записи защищены мьютексом.
- Время в сообщении формируется локальным временем системы.

## Пример инициализации

```cpp
#include "logger.h"

int main() {
    Logger::configure(LogLevel::Info);
    Logger::info("Server", "Сервер стартовал");
    Logger::warning("Network", "Проверка входящих соединений");
    Logger::error("Database", "Не удалось подключиться к базе данных");

    return 0;
}
'''
